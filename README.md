Landing Page To' Ricci - Actividad 5
Este proyecto consiste en el desarrollo de una landing page utilizando el framework Reflex. El objetivo principal fue reinterpretar un diseño profesional y llevarlo al código aplicando componentes de Python para el frontend.

-- Referencia de diseño --
Para este proyecto decidí tomar como referencia visual el sitio de The Row (https://www.therow.com/es?country=US). Me interesó su estética minimalista de lujo, el uso de tipografías clásicas y los fondos en tonos crema, que son los elementos que intenté plasmar en mi versión llamada To' Ricci.

Proceso de desarrollo paso a paso
1. Elección del concepto y estilos
Lo primero que hice fue definir la paleta de colores. En lugar de usar un blanco puro, configuré un tono hueso para el fondo y negro para los textos, buscando ese aire editorial que tienen las marcas de moda de alta gama.

2. Maquetación del Header
Creé una barra de navegación simple. En lugar de centrar todo, coloqué el nombre de la marca a la izquierda y las opciones de menú (Colección, Manifesto, Contacto) distribuidas a la derecha, manteniendo mucho espacio entre los elementos para que no se viera saturado.

3. Sección principal (Hero)
Aquí fue donde más tiempo dediqué a la tipografía. Usé componentes de texto en Reflex para jerarquizar el título "TO' RICCI". Debajo añadí un subtítulo pequeño en cursiva para darle un toque más elegante y un botón de "Descubrir la colección" con un diseño sobrio.

4. Organización del código
Para que el sitio fuera responsivo y estuviera ordenado, utilicé principalmente vstack y hstack. Dividí el proyecto en componentes pequeños para que el archivo principal no fuera un desastre y fuera más fácil de leer.

5. Ajustes finales y limpieza
Una vez que tuve el diseño visual listo, configuré el archivo .gitignore para evitar subir carpetas basura como .states o entornos virtuales. Me aseguré de que el repositorio estuviera limpio y que solo incluyera los archivos necesarios para ejecutar la aplicación (el código fuente, los assets y los requerimientos).

Requisitos para ejecutarlo
Es necesario tener instalado Reflex y Python.

Clonar el repositorio.

Instalar las dependencias con pip install -r requirements.txt.

Ejecutar el comando reflex run para ver la página en el navegador.
